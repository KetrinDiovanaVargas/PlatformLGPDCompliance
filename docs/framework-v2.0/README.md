## 🎯 Os 4 Estágios

### E1: Contexto Organizacional (4 perguntas)
- Com que frequência sua organização realiza contato com dados pessoais?
- Qual é a percepção geral sobre importância da proteção?
- Qual cenário descreve melhor a relação com dados?
- Como você descreveria o nível de conhecimento da equipe?

### E2: Controles e Processos (3 perguntas)
- Quais controles sua organização possui para limitar acesso?
- Como sua organização documenta e rastreia circulação?
- **Quais medidas de segurança no armazenamento?** ✅ NOVO

### E3: Riscos e Governança (3 perguntas)
- Sua organização compartilha dados com terceiros?
- Como são definidas as responsabilidades pelos dados?
- **Qual é o estado das dependências técnicas?** ✅ NOVO

### E4: Maturidade e Evidências (3 perguntas)
- **Sua organização possui políticas documentadas?** ✅ NOVO
- **Com que frequência realiza auditorias?** ✅ NOVO
- Qual é o grau de maturidade geral dos controles?
